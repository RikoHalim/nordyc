# 08 — Judge Demo Workflow (Once Backend Works)

Use only public/open data and obviously synthetic syllabi where official ones are unavailable. Do not misrepresent a real university course's quality.

## 3–5 minute narrative

**1. Show complete programme import.** Institution XMUM, programme Software Engineering. List **all detected compulsory and elective courses** with a file/evidence indicator. Explain this is not a one-course app.

**2. Show evidence-based diagnosis.** Open one course for which the sample includes detailed CLOs. Display which foundational knowledge remains important, what documented AI development affects related professional tasks, and what in the syllabus is assessed or not evidenced. Show another inventory-only course classified `INSUFFICIENT_EVIDENCE`.

**3. Show automatic action choice.** AI recommends `REVISE_SYLLABUS` where the sample supports that outcome. Staff can compare `KEEP_NO_CHANGE`, an elective and workshop/industry engagement; the recommendation explains why least-disruptive action wins. Avoid declaring real XMUM curriculum inadequate.

**4. Show programme-level intelligence.** Identify one skill/occupation change relevant across several courses and whether a programme-wide elective or hands-on workshop is more appropriate. Demonstrate that a career talk provides awareness but not verified mastery.

**5. Replay a changed signal.** Switch from `SYN-Q1` to `SYN-Q2`, re-run same programme and compare outputs with sources, timestamps, and reasons. No invented rates or employment probabilities.

**6. Show academic action report.** Programme inventory counts, proposed interventions, supporting citations, alternative tradeoffs, SDG 4/8 rationale where justified, unresolved questions and `PENDING_REVIEW`. University staff decide what to submit for academic approval.

## Important presentation language

Say **'hypothetical model recommendation based on clearly synthetic syllabus assumptions'** for sample courses. Never say **'SHIFT//OS proved the official XMUM course is outdated'** unless actual verified syllabi and substantive sources support it.

## Product differentiator

An auditable, reproducible loop of **curriculum → dated workforce/AI evidence → full-programme relevance review → minimum sufficient intervention → human approval → re-evaluation when sources change**. Basic skill matching / dashboard charts are not inherently novel.
