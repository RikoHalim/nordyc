## Evidence coverage boundaries

The verified catalogue breadth is stronger than analysis depth. Computing, business/accounting and communication have suitable initial academic references and task evidence. Engineering has a professional standard access/applicability gate. Marine biotechnology has a candidate biotech benchmark; marine environmental chemistry, physics and mathematics need dedicated disciplinary checks. Language/literature and Chinese Studies must retain non-occupational educational purposes. TCM requires its own professional context and cannot inherit generic language-model or pharma-sector claims.

No genuine public course-to-skill truth set, verified assessment outcomes, placement rates, employer partnership list, university budget/staffing data or future AI adoption probabilities were obtained. None is required to import public course titles or issue cautious investigation prompts. They cannot be fabricated to make the demonstration look complete.

## Explicit fallback package

If automated collection is unavailable, use permitted manually saved official pages/files and validated metadata manifests with original URLs, then import through a later approved manual path. If source-text reuse is restricted, retain metadata/source links and reviewed paraphrases where permitted; omit protected raw documents from Git. If field/task evidence is weak, return investigation/abstention. If an offline pipeline needs rich content or forced changes for an engineering test, use an invented, clearly synthetic institution/curriculum and signal set, separate from real XMUM records.

Real DOSM snapshots can demonstrate dated context/replay without synthetic demand values. Adoption scenarios remain stated assumptions; an academic recommendation need not change just because an aggregate count changed. No synthetic learning outcome may be attached to a real university course as a verified fact.
