# PHASE 8 — Minimal hackathon-ready UI and demo

**Only begin if backend end-to-end scenario is working.** Read product requirements, demo and compliance docs.

Build a simple, clean, responsive application (React/TypeScript or well-justified alternative) that connects to real backend endpoints: institution/programme explorer (all publicly discoverable XMUM programmes), programme-wide analysis, course detail evidence inspector, primary AI suggestion vs alternative/no change comparison, scenario/source snapshot toggle, and a source-backed draft report. Include a concise live demo script, README startup/run/test commands, GitHub reproducibility checklist and screenshot. Audit unresolved original six-feature compliance gap rather than falsely marking it satisfied. Do not build generic chatbot, event scheduler, login/payment system or unrelated screens. Run E2E demo, update STATUS and STOP.
