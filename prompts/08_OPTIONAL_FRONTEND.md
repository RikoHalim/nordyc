# CODEX PROMPT — Phase 08 (DEFERRED): Minimal Frontend

**Do not execute until Phase 07 backend acceptance gates pass.**

Build a minimal React + TypeScript institutional UI from tested backend OpenAPI, with a clean professional style and black/dark neutral body text. No fictional 'demo' data passing as real results.

Primary flow:
1. University name + programme + **programme-wide** curriculum/syllabus uploads; no CV, no country field, no budget or planning period at onboarding.
2. Full course inventory with filters by evidence status, recommendation and mandatory/elective.
3. Programme-level course relevance dashboard and potential cross-course curriculum gaps.
4. Drill down into a course to see documentary evidence, AI developments, unchanged foundations, uncertainties, model version and proposed action.
5. AI-selected primary recommendation shown first; alternatives comparable, including justified no change; workshop/industry engagement formats as one category.
6. Two scenario comparison and source-snapshot replay; final report and explicit pending/approved faculty review state.

UX guard: when all only-course-name data is available, show insufficient-evidence messaging, **not fabricated scores**. Never place single-course selection before programme-wide ingestion.
